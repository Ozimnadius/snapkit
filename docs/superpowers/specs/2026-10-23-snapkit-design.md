## 1. Зачем это нужно

Пользователь — веб-разработчик (сайты на 1С-Битрикс и PHP), работает с ИИ-агентами:
Claude Desktop (в том числе вкладка Code) и чатами в браузере (claude.ai, ChatGPT).
Часто нужно показать агенту, что не так на экране: «вот это поле съехало», «у Макса значок VK
в админке». Сейчас это несколько скриншотов и отдельное словесное объяснение, где что
находится.

Программа сводит это к одному потоку:
1. нажал клавишу и выделил область;
2. обвёл проблемное место и написал к нему комментарий — на картинке появляется кружок **A1**;
3. при необходимости снял ещё несколько снимков — они копятся в ленте у края экрана;
4. перешёл в чат и нажал Ctrl+V — в поле ввода по очереди вставились все картинки,
   а за ними текст с комментариями, привязанными к кружкам.

Сообщение пользователь отправляет сам, Enter программа не нажимает.

Главный смысл — связка «кружок на картинке ↔ строка в тексте». ИИ видит A1 на снимке
и читает «A1 — значок VK вместо Max» в тексте.

## 2. Пользователь и окружение

- Один пользователь — автор. Программа личная, не для продажи и не для распространения.
- Windows 11 Pro x64, мониторов может быть несколько, масштаб экрана может отличаться от 100 %.
- Пользователь **не читает по-английски**: весь интерфейс, сообщения, уведомления
  и документация только на русском. Комментарии в коде — тоже на русском.
- Код сам править не будет: доработки делает Claude **[решено]**.
- **Важно:** у пользователя работает скрипт AutoHotkey:
  ```
  +WheelDown:: Send ^c    ; Shift + колесо вниз  → Ctrl+C
  +WheelUp::   Send ^v    ; Shift + колесо вверх → Ctrl+V
  +MButton::   Send ^x    ; Shift + средняя кнопка → Ctrl+X
  ```
  То есть Ctrl+V часто приходит не с клавиатуры, а как программно сгенерированное нажатие
  от AutoHotkey, и в этот момент физически зажат Shift. Перехват вставки обязан работать
  в этом случае (см. раздел 7).

Стиль **[решено: как Snapik]**: тёмные полупрозрачные панели со скруглёнными углами,

По умолчанию тема «Тёмная», акцент синий.

### 5.1. Снимок области

- Глобальная клавиша **«Сделать скриншот»**, по умолчанию **Print Screen** **[решено]**.
  Кнопка «Новый снимок» в ленте делает то же самое.
- В Windows 11 Print Screen по умолчанию открывает «Ножницы». Snapkit должен получить
  нажатие раньше: тот же низкоуровневый хук клавиатуры, что и для Ctrl+V (раздел 7.3),
  перехватывает и подавляет Print Screen. Если «Ножницы» всё равно открываются,
  программа один раз показывает подсказку с кнопкой, которая открывает нужную страницу
  параметров Windows («Специальные возможности → Клавиатура → Использовать кнопку
  Print Screen для открытия «Ножниц»»). Отключает пользователь сам: программа настройки
  Windows не меняет **[моё решение; строителю — проверить, хватает ли хука]**.
- Сразу после нажатия программа фиксирует изображение всех мониторов. Поверх них
  открывается окно на весь экран, где показан этот застывший кадр, затемнённый примерно
  наполовину.
- Мышью выделяется прямоугольник: внутри он показывается без затемнения, вокруг синяя
  рамка с маркерами по углам и серединам сторон. Рядом с рамкой при выделении видны
  размеры в пикселях **[моё решение]**. Подсказка: «Выделите область · Esc отменяет».
- Если включено «Предлагать ту же область, что в прошлый раз», выделение сразу стоит там,
  где было в прошлый раз, и его можно принять или выделить заново.
- После выделения рамку можно тянуть за маркеры и двигать — это «изменить границы
  снимка». Под областью (если места нет — над ней) появляется панель инструментов,
  справа на экране — панель «Комментарии» (раздел 6).
- Esc на этапе выделения отменяет снимок.
- Несколько мониторов с разным масштабом: выделение, координаты и итоговое изображение
  должны совпадать пиксель в пиксель с тем, что было на экране. Программа должна
  учитывать масштаб отдельно для каждого монитора.
- «Показывать курсор мыши на скриншоте» (настройка, по умолчанию выключено) — курсор
  дорисовывается на кадр.
- Ровно один снимок за раз: если режим снимка уже открыт, повторное нажатие клавиши
  ничего не делает.

### 5.2. Снимок всего экрана

- Отдельная глобальная клавиша **«Снимок всего экрана»**, по умолчанию не назначена.
  В настройках есть кнопка «Предложить: Ctrl+Print Screen» **[моё решение: в Snapik
  здесь предлагался Print Screen, но он теперь занят основным снимком]**.
- Снимается монитор, на котором сейчас курсор. Дальше открывается тот же редактор,
  где выделением уже служит весь монитор **[моё решение]**.

## 6. Редактор разметки

### 6.1. Где он открывается

- **Новый снимок:** редактор работает прямо в окне снимка — выделенная область на своём
  месте, вокруг затемнение.
- **Повторное открытие из ленты:** снимок появляется **на том же месте экрана, где его
  сняли**, поверх текущих окон, с той же рамкой, панелью инструментов и панелью
  комментариев **[решено, по скриншоту Snapik]**. Если тех координат больше нет (монитор
  отключён), снимок показывается по центру основного монитора, при необходимости
  уменьшенным.
- Разметка хранится отдельно от картинки: фигуры остаются объектами, их можно выбрать,
  сдвинуть, поменять или удалить при каждом открытии. Готовое изображение собирается
  из исходного снимка и фигур в момент копирования, вставки или сохранения.

### 6.2. Панель инструментов (слева направо, как в Snapik)

| Кнопка | Что делает |
|---|---|
| Выбор | выделить фигуру, двигать, менять размер маркерами, Delete удаляет |
| Фигура ▾ | прямоугольник, скруглённый прямоугольник, овал |
| Стрелка ▾ | прямая, изогнутая (с точкой изгиба, которую можно тянуть), широкая (клином) |
| Линия | прямая линия |
| Карандаш ▾ | карандаш (свободное рисование), маркер (широкий полупрозрачный выделитель) |
| Текст | надпись по клику, размер шрифта настраивается |
| Ластик | клик по фигуре удаляет её целиком **[моё решение: удаляет фигуры, а не стирает пиксели]** |
| Размыть | прямоугольник, внутри которого снимок размыт (скрыть пароли, телефоны) |
| Обрезать | обрезать снимок; фигуры за краем обрезаются, кружки сдвигаются внутрь |
| Комментарий | поставить отметку-кружок без фигуры в любую точку (см. 6.3) |
| ? | подсказка со всеми сочетаниями клавиш редактора |
| Цвет обводки / цвет заливки | палитра отметок + свои сохранённые цвета, ввод HEX, оттенок и яркость, пипетка «взять цвет с экрана» |
| Толщина ▾ | толщина в px и стиль линии: сплошная, пунктир, точки |
| Отменить / Повторить | Ctrl+Z / Ctrl+Y (и Ctrl+Shift+Z) |
| Сохранить на компьютер | Ctrl+S — сохраняет картинку в папку сохранения без диалога, во всплывающем сообщении путь к файлу **[моё решение]** |
| Копировать | Ctrl+Shift+C — кладёт этот снимок как картинку в буфер обмена (обычная вставка, без перехвата) |
| **Готово** | Enter вне поля ввода — снимок уходит в ленту, окно закрывается |

- У фигур настраиваются заливка (нет, сплошная, полупрозрачная, размытием) и контур.
  Настройки зависят от инструмента и показываются, только когда к нему применимы.
- Последние выбранные цвет, толщина и стиль запоминаются между снимками.
- Клавиши инструментов (одна буква на инструмент) **[строителю]**, их список выводится
  по кнопке «?».
- Esc в редакторе отменяет снимок. Если на снимке есть разметка, сначала спросить
  подтверждение. Для снимка, открытого из ленты, Esc закрывает редактор без изменений
  **[моё решение]**.

### 6.3. Комментарии и кружки

Это главное отличие программы от обычных скриншотеров.

- После того как нарисована фигура (рамка, овал, стрелка, линия, карандаш, маркер,
  размытие), **прямо под ней всплывает поле ввода комментария** с крестиком
  **[решено, по скриншоту Snapik]**. Enter завершает заметку, Shift+Enter переносит
  строку, крестик или Esc закрывают поле.
- Если пользователь ничего не написал и начал рисовать дальше, поле исчезает, фигура
  остаётся без комментария и без кружка.
- Если комментарий есть, у левого верхнего угла фигуры появляется **кружок цвета акцента
  с меткой вида A1**: буква — снимок, число — порядковый номер заметки на этом снимке.
  Кружок можно немного сдвинуть мышью, чтобы не закрывал важное («Переместить заметку»).
- Инструмент «Комментарий»: клик в любую точку ставит кружок без фигуры и сразу открывает
  поле ввода.
- Панель **«Комментарии»** у правого края экрана — список всех заметок снимка
  («A1 У Макса значок VK в админке»). Клик по пункту выделяет фигуру, текст можно
  исправить, пункт можно удалить. Внизу панели поле «Комментарий к снимку» — общая
  заметка ко всему снимку, без кружка.
- Кружки входят в итоговую картинку: ИИ должен их видеть.
- Удалили заметку — номера остальных на этом снимке перенумеровываются по порядку
  (A1, A2, A3 без дыр) **[моё решение]**.

### 6.4. Буквы снимков

- Буква (A, B, C…) — это позиция снимка **среди неотправленных снимков ленты**, в том
  порядке, в котором они уйдут в чат. Первый неотправленный — A, второй — B и так далее
  **[решено: в ленте Snapik новый неотправленный снимок помечен «A», хотя выше лежат
  три отправленных]**.
- Сменился порядок или часть снимков отправлена — буквы пересчитываются. Кружки
  на картинке рисуются с актуальной буквой в момент вставки, поэтому картинка и текст
  всегда совпадают.
- Отправленные снимки буквы не имеют. Если открыть и изменить отправленный снимок,
  он снова становится неотправленным и получает букву **[моё решение]**.

### 6.5. Что такое «пакет» и как отправить снимки ещё раз

Единое правило для вставки, «Копировать пакет» и «Сохранить пакет…» **[моё решение]**:
- **Пакет** — это неотправленные снимки ленты в её порядке, с буквами A, B, C…
- Если неотправленных нет, «Копировать пакет» и «Сохранить пакет…» берут **всю ленту**:
  все снимки снова становятся неотправленными, и буквы раздаются заново с A. Так ту же
  пачку можно вставить во второй чат (например, сначала в Claude, потом в ChatGPT).
- На карточке отправленного снимка в меню по правому клику есть «Отправить ещё раз» —
  снимок снова становится неотправленным и встаёт в пакет.
- Если вставка не прошла (остановлена или не подтверждена и на деле не дошла),
  пользователь повторяет её через «Копировать пакет».

## 7. Вставка пачки по Ctrl+V — сердце программы

### 7.1. Что видит пользователь

1. В ленте есть неотправленные снимки (счётчик в заголовке ленты больше 0).
2. Пользователь в любом окне ставит курсор в поле ввода и нажимает Ctrl+V — на клавиатуре
   или через Shift+колесо вверх (AutoHotkey).
3. В поле по очереди вставляются все неотправленные снимки (A, B, C…) с кружками,
   а затем текст с комментариями (формат в 7.4).
4. Снимки в ленте получают галочки, счётчик становится 0. Если включено «Очищать ленту
   после вставки» — лента очищается.
5. Всплывает сообщение: «Вставлено: 2 изображения и 3 заметки».

Перехват работает **в любом окне** **[решено]**. В программах, которые не принимают
картинки (например PhpStorm), вставится только текст. Это нормально.

### 7.2. Когда Ctrl+V перехватывается, а когда нет

Ctrl+V перехватывается, только если **одновременно**:
- в ленте есть неотправленные снимки;
- **после последнего снимка пользователь ничего не копировал**: в буфере обмена до сих
  пор лежит то, что туда положила программа **[моё решение — защищает обычную вставку]**;
- активное окно — не окно самой программы (лента, редактор, настройки);
- нажат именно Ctrl+V (без Alt и Win). Shift при этом может быть зажат — это случай
  AutoHotkey.

Во всех остальных случаях Ctrl+V проходит как обычно.

Чтобы проверять второе условие, после каждого «Готово» программа кладёт в буфер
«пакет» и запоминает номер изменения буфера (`GetClipboardSequenceNumber`). Если номер
сменился — кто-то положил в буфер своё, и пакет считается вытесненным. Тогда на ленте
появляется подсказка «Пакет вытеснен — нажмите «Копировать пакет», чтобы вставить
снимки» **[моё решение]**. Пункт меню «Копировать пакет» снова кладёт пакет в буфер
и включает перехват.

Пакет в буфере должен вставляться и без перехвата (если перехват по какой-то причине
не сработал): в нём есть картинка последнего снимка (форматы PNG и DIB) и текст
комментариев **[строителю: точный набор форматов]**.

### 7.3. Как устроена вставка (требования и рекомендуемый путь)

Требования:
- Перехват — через низкоуровневый хук клавиатуры (`WH_KEYBOARD_LL`). Он должен ловить
  и **программно сгенерированные** нажатия (флаг `LLKHF_INJECTED`, так приходит Ctrl+V
  от AutoHotkey). Свои собственные сгенерированные нажатия программа помечает (например,
  через `dwExtraInfo`) и не перехватывает.
- Перехваченное нажатие V (и его отпускание) подавляется. Ctrl не подавляется.
- Сама вставка идёт **после** выхода из обработчика хука, асинхронно. Обработчик хука
  должен возвращаться мгновенно, иначе Windows снимет хук и начнутся задержки при наборе.
- Каждая картинка вставляется так: положить в буфер одну картинку → убедиться, что
  активно то же окно → отправить Ctrl+V (`SendInput`) → дождаться, пока получатель
  забрал данные → следующая. После картинок так же вставляется текст.
- **Модификаторы.** На момент отправки Ctrl+V зажатые Shift, Alt и Win не должны на неё
  влиять: в Chrome и Claude Desktop Ctrl+Shift+V вставляет только текст, и картинки
  пропадут. Перед каждым Ctrl+V нужно программно отпускать модификаторы, которые сейчас
  считаются нажатыми, а после вставки вернуть Shift, если он всё ещё физически зажат.
  Ни одна клавиша не должна остаться залипшей.
- Если активное окно сменилось или пользователь нажал Esc — остановиться. Сообщение
  «Вставка остановлена», неотправленные снимки остаются неотправленными.
- Промежуточные картинки желательно не засорять в журнале буфера обмена Windows (Win+V).
  Для этого есть формат `ExcludeClipboardContentFromMonitorProcessing`
  **[строителю: проверить, что не мешает вставке]**.
- После вставки в буфере остаётся текст комментариев (последнее вставленное). Перехват
  выключен, пока не появится новый неотправленный снимок **[моё решение]**.

Рекомендуемый способ узнать, что получатель забрал картинку **[строителю: проверить
на практике]**: класть данные в буфер с отложенной выдачей (`SetClipboardData` с `NULL`
и обработка `WM_RENDERFORMAT`). Запрос данных от процесса активного окна
(`GetOpenClipboardWindow` → процесс) означает «забрал». Запросы от других процессов
(журнал буфера, менеджеры буфера) не считаются. Если подтверждения нет за разумное
время — продолжить с фиксированной паузой и отметить вставку как «не подтверждённую»
(снимки всё равно помечаются отправленными, в сообщении сказано, что проверить вставку
не удалось).

Задержки между шагами подобрать так, чтобы пачка из 5 снимков вставлялась за 1–2 секунды
и не терялась ни одна картинка **[строителю]**.

### 7.4. Текст для чата

Формат **[моё решение]**:

```text
Снимок A
A1 — У Макса значок VK в админке
A2 — Поле Telegram шире остальных
Комментарий к снимку: страница настроек соцсетей

Снимок B
B1 — Кнопка «Сохранить» не активна
```

- Снимки без комментариев в текст не попадают. Если комментариев нет вообще, текст
  не вставляется, только картинки.
- Многострочный комментарий выводится с отступом под своей меткой.

### 7.5. Ограничение на количество

Чаты принимают ограниченное число картинок за раз. В ленте не больше **20** снимков.
С 10 неотправленных на ленте видна мягкая подсказка «Чаты обычно принимают до 10 картинок
за раз» **[моё решение, числа можно поменять]**.

## 8. Лента снимков

По скриншотам Snapik **[решено]**:
- Узкое окно (около 230 px), по умолчанию у правого края основного монитора.
  Перетаскивается за заголовок, позиция запоминается.
- **Заголовок:** значок и название программы, счётчик неотправленных снимков, кнопки
  «Очистить» (корзина), «…» (меню), «Свернуть», «Закрыть».
- **Карточки стопкой:** каждая следующая лежит на предыдущей и перекрывает её, новая
  добавляется снизу и видна целиком, от остальных видна верхняя полоса. На карточке
  буква в синем кружке (неотправленный) или галочка (отправленный) и значок комментария
  с числом заметок.
- Наведение на карточку показывает её крупнее и кнопки «Копировать снимок» и «Удалить»
  **[моё решение]**. Клик открывает снимок в редакторе. Перетаскивание меняет порядок.
- Удалённый снимок можно вернуть: всплывает сообщение «Снимок удалён» с кнопкой
  «Вернуть».
- Внизу большая кнопка цвета акцента «Новый снимок». В пустой ленте подсказка
  «Нажми Print Screen или «Новый снимок»» (с текущей клавишей).
- «Свернуть» превращает ленту в маленькую капсулу со значком и счётчиком, клик
  разворачивает.
- «Очистить» спрашивает «Удалить снимки сессии?» с галочкой «Больше не спрашивать».
- «Закрыть» прячет ленту и удаляет снимки (с тем же вопросом, если есть неотправленные).
  Программа остаётся работать у часов **[моё решение, так устроено в Snapik]**.
- Лента по умолчанию «Поверх других окон».

**Меню «…»** **[решено, без «Лицензии», «О программе», «Что нового»]**:
- ✓ Поверх других окон
- Импортировать файл… (PNG или JPEG как новый снимок)
- Вставить изображение из буфера (картинка из буфера как новый снимок)
- Очистить ленту
- Копировать пакет
- Сохранить пакет…
- Настройки
- Выйти

## 9. Сохранение

- **Автосохранение** (настройка, по умолчанию выключено): каждый снимок после «Готово»
  сразу сохраняется в папку сохранения с разметкой. Имя файла — дата и время
  (`2026-10-23_15-40-12.png`).
- **Формат:** PNG (по умолчанию) или JPEG с настраиваемым качеством (по умолчанию 90 %).
- **Папка сохранения** по умолчанию — `Изображения\Snapkit`.
- **«Сохранить пакет…»** открывает окно: куда (по умолчанию папка сохранения), имя папки
  (по умолчанию дата и время), галочка «Создать подпапку». Внутрь ложатся снимки пакета
  (правило в 6.5) `A.png`, `B.png`, … с разметкой и `prompt.md` — тот же текст, что
  уходит в чат, со ссылками на файлы картинок **[решено, как в Snapik]**. Сохранение
  пакета не помечает снимки отправленными. Если папка с таким именем занята — добавить
  к имени номер.

## 10. Настройки

Окно с вкладками «Общие / Клавиши / Сохранение / Вид», внизу «Отмена» и «Сохранить»
**[решено, по скриншотам Snapik]**.

**Общие:**
- Открывать при включении компьютера (по умолчанию включено)
- Показывать уведомления
- Очищать ленту после вставки (по умолчанию выключено)
- Предлагать ту же область, что в прошлый раз
- Показывать курсор мыши на скриншоте
- Звуки + ползунок громкости

**Клавиши:**
- Сделать скриншот — поле «Нажми, чтобы изменить» (по умолчанию Print Screen)
- Снимок всего экрана — по умолчанию «Не назначено», кнопка «Предложить: Ctrl+Print Screen»
- У каждого действия есть галочка «включено».
- Проверки: в сочетании должен быть Ctrl, Alt или Shift (кроме Print Screen и F1–F12),
  одно сочетание нельзя назначить на два действия, занятое другой программой сочетание
  вызывает понятное сообщение.

**Сохранение:** автосохранение, формат PNG/JPEG (+ качество JPEG), папка с кнопкой обзора.

**Вид:**
- Тема — карусель карточек с превью. Набор из 5–7 тем: тёмная (по умолчанию), светлая
  и несколько цветных **[строителю: названия и цвета]**. Тема с эффектом стекла — если
  получится через системный фон Windows 11, иначе без неё.
- Цвет акцента — 6 однотонных и 6 градиентных кружков. Акцент красит рамку выделения,
  кнопки и кружки заметок.
- Палитра отметок: Стандартная, Пастель, Неон, Своя — цвета для инструментов разметки.
- Образец «так будут выглядеть отметки»: рамка, кружок с номером, кнопка «Готово».
  Меняется сразу при выборе.

Настройки хранятся в файле JSON в профиле пользователя. Если файл повреждён, создаётся
новый с настройками по умолчанию, а пользователь получает сообщение.

## 11. Сессия и восстановление

- Снимки ленты (исходные картинки и разметка) хранятся на диске в рабочей папке
  программы в профиле пользователя, а не только в памяти.
- Если программа упала, компьютер перезагрузился или выключился — при следующем запуске
  лента восстанавливается: «Снимки восстановлены после сбоя».
- Закрытие ленты, «Очистить» и выход из программы удаляют снимки сессии
  (с подтверждением, если есть неотправленные). Временные файлы удаляются вместе с ними.
- Запись на диск не должна тормозить работу: сохранять в фоне и надёжно
  (запись во временный файл и замена) **[строителю]**.

## 12. Звуки и уведомления

- Звуки: щелчок затвора при снимке, тихий «тик», когда снимок ложится в ленту, мягкий
  сигнал после вставки. Громкость из настроек. Звуки свои: синтезировать или взять
  свободные (CC0). **Звуки Snapik не использовать.**
- Уведомления — небольшое всплывающее окно у правого нижнего угла экрана («Скопировано»,
  «Сохранено», «Вставлено: …», «Вставка остановлена», «Снимок удалён — Вернуть»).
  Окно исчезает само через 2–3 секунды. Системные уведомления Windows не используем:
  они медленные и копятся в центре уведомлений **[моё решение]**.

## 13. Установка и сборка

- Программа собирается из исходников у пользователя на компьютере. Готовая сборка не
  зависит от установленного .NET и кладётся в `%LOCALAPPDATA%\Programs\Snapkit`.
  Ярлык в меню «Пуск» **[моё решение]**.
- Скрипт сборки одной командой: собрать → закрыть работающую программу → заменить файлы
  → запустить заново. Так доставляется каждая доработка.
- Автозапуск — через запись в `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`.
- Одновременно работает только одна копия программы. Повторный запуск показывает ленту
  уже работающей копии.
- Значок программы — свой, простой **[строителю]**.

## 14. Как поймём, что получилось

Ручная проверка (главный сценарий):
1. Print Screen → выделить область → обвести рамкой → написать комментарий → появился
   кружок A1 → «Готово». Снимок в ленте с буквой A и числом заметок 1.
2. Ещё один снимок со стрелкой и двумя комментариями → в ленте A и B.
3. Перейти в Claude Desktop, клик в поле ввода, **Shift+колесо вверх** → в поле две
   картинки с кружками и текст «Снимок A / A1 — … / Снимок B / B1 — … / B2 — …».
   Сообщение не отправлено, Shift и Ctrl не залипли.
4. То же в Chrome на claude.ai и в ChatGPT — обычным Ctrl+V на клавиатуре.
5. Сделать снимок, затем скопировать строку в PhpStorm и нажать Ctrl+V → вставилась
   строка, а не снимки. На ленте подсказка «Пакет вытеснен». «Копировать пакет» →
   Ctrl+V в чате вставляет пачку.
6. Во время вставки пачки из 5 снимков переключиться в другое окно → вставка
   остановилась, в другое окно ничего не попало.
7. Открыть снимок из ленты → он на том же месте экрана, разметку можно изменить,
   кружки на месте.
8. Два монитора с разным масштабом: снимок на втором мониторе совпадает с экраном
   пиксель в пиксель.
9. Сделать 2 снимка, завершить процесс программы через Диспетчер задач, запустить
   заново → снимки в ленте.
10. «Сохранить пакет…» → в папке `A.png`, `B.png`, `prompt.md`.

Автоматические тесты — для логики без экрана: нумерация букв и заметок, текст
для чата, обрезка и перенос фигур, сохранение и чтение сессии и настроек, правила
перехвата Ctrl+V (условия из 7.2).

## 15. Что остаётся строителю

- Внутреннее устройство: проекты, классы, слои.
- Точные цвета тем, размеры, отступы, анимации — в духе скриншотов Snapik.
- Буквенные клавиши инструментов в редакторе.
- Точные задержки и таймауты вставки, способ подтверждения (7.3).
- Набор форматов буфера для «пакета».
- Иконки и значок программы, звуки (свои).
- Порядок разработки и разбиение на этапы.

## 16. Snapik и переход

- Snapik больше не используется **[решено]**. До первой проверки Snapkit пользователь
  закрывает Snapik и убирает его из автозапуска, чтобы две программы не делили
  Print Screen, Ctrl+V и буфер обмена.
- Открытых вопросов к пользователю нет.
