# Snapkit, этап 3 — приёмка

Что проверить вместе с пользователем перед слиянием ветки `feat/stage-3-strip` в `main`.
Программу ставит `build.ps1` (запускает Snapkit через Проводник). Журнал — `%LOCALAPPDATA%\Snapkit\log.txt`
(из терминала Claude читать процессом вне пакета, см. README и память).

## Перед началом (делает Claude)

- [x] Полный прогон `dotnet test Snapkit.slnx` (с буфером обмена и окнами) — зелёный (ядро 301, приложение 158).
- [ ] `build.ps1` — сборка установлена и запущена.

## Проверки

- [ ] **1. Пачка с ленты.** Три снимка A, B, C. Щелчок по букве B — у неё галочка, буквы
  стали A, B; Ctrl+V в чате вставляет два снимка. Щелчок по галочке — снимок снова в пачке.
- [ ] **2. Повтор вставки.** После вставки «…» → «Повторить последнюю вставку» — та же пачка
  снова с буквами, Ctrl+V во втором чате вставляет её. То же после вставки, остановленной Esc.
  «Вся лента в пачку» — все снимки с буквами.
- [ ] **3. Порядок.** Перетащить нижнюю карточку наверх — буквы и порядок вставки в чат меняются.
  Обычный щелчок по карточке по-прежнему открывает снимок.
- [ ] **4. Файл в другое окно.** Перетащить карточку в Telegram, в Проводник и в форму загрузки
  в браузере — приходит PNG `Снимок A.png` с разметкой и размытием.
- [ ] **5. Сохранение.** «Сохранить снимок…» на карточке — PNG с разметкой, имя по времени,
  папка `Изображения\Snapkit`, в следующий раз — последняя выбранная. «…» → «Сохранить
  пакет…» — папка с A.png, B.png… и `prompt.md`; «Открыть папку» в уведомлении.
- [ ] **6. «Вернуть».** Удалить карточку — уведомление «Снимок удалён», «Вернуть» ставит снимок
  на место с той же буквой или галочкой.
- [ ] **7. Импорт.** «…» → «Импортировать файл…» с PNG и JPEG; перетащить файлы из Проводника
  на ленту — появляются новые снимки.
- [ ] **8. «Показывать ленту».** Снять галочку (меню значка у часов или «…») — лента пропадает;
  после снимка уведомление «Снимок A готов — Ctrl+V вставит», Ctrl+V вставляет. Вернуть
  галочку — лента на месте.
- [ ] **9. 21-й снимок.** При 20 снимках с отправленными новый вытесняет самый старый
  отправленный; при 20 неотправленных снимок не начинается, сообщение и лента.
- [ ] **10. Вид ленты.** Рядом со Snapik: полоски показывают снимки, стопка компактная,
  наведение раскрывает карточку с кнопками.
- [ ] **11. Капсула.** «Свернуть» — капсула со счётчиком; новый снимок — капсула остаётся,
  счётчик растёт; кнопка с фотоаппаратом делает снимок; «˄» разворачивает; капсулу можно
  перетащить; после перезапуска свёрнутая лента появляется капсулой.
- [ ] **12. Звуки.** Затвор при снимке, «тик» после «Готово», сигнал после вставки; галочка
  «Звуки» у часов выключает их.

- [ ] **13. По стопке подряд.** Вести мышь сверху вниз по полоскам — раскрывается та карточка,
  что под мышью; щёлкнуть значки нескольких карточек подряд, не уводя мышь с ленты.
- [ ] **14. Буфер не подменяется.** «Копировать снимок» на одной карточке, затем переставить
  карточки — Ctrl+V вставляет один скопированный снимок.
- [ ] **15. Повтор после очистки.** «Очистить» ленту, сделать новый снимок — «Повторить
  последнюю вставку» неактивна или сообщает, что снимков той вставки нет; новый снимок
  остаётся в пачке.
- [ ] **16. Бросок мимо.** Перетащить карточку и отпустить на заголовке или «Новый снимок» —
  порядок не меняется; над списком видна линия «сюда встанет».
- [ ] **17. Панель комментариев справа** — в редакторе при снимке у правого и у левого края.
