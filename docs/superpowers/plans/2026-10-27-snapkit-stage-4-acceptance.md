# Snapkit, этап 4 — приёмка

Что проверить вместе с пользователем перед слиянием ветки `feat/stage-4-settings` в `main`.
Программу ставит `build.ps1` (запускает Snapkit через Проводник). Журнал — `%LOCALAPPDATA%\Snapkit\log.txt`.
Описание — `docs/superpowers/specs/2026-10-27-snapkit-stage-4-design.md`, номера разделов — оттуда.

## Перед началом (делает Claude)

- [x] Полный прогон `dotnet test Snapkit.slnx` (с буфером обмена и окнами) — зелёный (ядро 339, приложение 175).
- [x] `build.ps1` — сборка установлена и запущена.

## Проверки

- [ ] **1. Окно (2.1).** «Настройки…» открывается из меню значка у часов и из «…» на ленте; второй
  вызов выводит то же окно вперёд. «Отмена» и ✕ ничего не меняют, «Сохранить» применяет сразу.
- [ ] **2. Общие (2.2).** Каждая галочка после «Сохранить» меняет поведение: автозапуск (запись
  в автозагрузке Windows), уведомления (ошибки всё равно видны), «Показывать ленту» (и в меню
  ленты, и у значка), «Очищать ленту после вставки».
- [ ] **3. Клавиши (2.3).** Щёлкнуть поле, нажать Print Screen — записалось, снимок не начался
  и «Ножницы» Windows не открылись. Два сочетания у снимка области работают оба. Повтор
  сочетания и сочетание без Ctrl/Alt/Shift — сообщение под полем, «Сохранить» бледнеет.
  Esc отменяет ввод, Backspace очищает поле.
- [ ] **4. Весь экран (2.3).** «Предложить: Ctrl+Print Screen», «Сохранить»; Ctrl+Print Screen
  на втором мониторе — сразу редактор с этим монитором целиком.
- [ ] **5. Та же область (2.4).** Галочка включена: снимок, затем снова Print Screen — прежняя
  рамка стоит, редактор открыт, Enter — «Готово». Рамку можно потянуть или нарисовать новую.
  После перезапуска программы — то же.
- [ ] **6. Курсор (2.5).** Галочка включена — указатель виден на снимке; выключена — нет.
- [ ] **7. Автосохранение (2.6).** Включить, сделать снимок — в папке сохранения файл по времени
  снимка; поправить снимок с ленты — тот же файл обновился, копии нет.
- [ ] **8. JPEG и папка (2.6).** Формат JPEG, качество 50 — «Сохранить снимок…» и «Сохранить
  всё…» пишут `.jpg` (в `prompt.md` ссылки на `.jpg`); перетаскивание в Telegram — по-прежнему
  PNG. Другая папка сохранения — окна сохранения открываются в ней.
- [ ] **9. Темы (2.7).** Светлая — лента, капсула, уведомления, редактор (инструменты,
  комментарии, меню цвета и толщины), окно настроек и меню «…» читаются; «Как в Windows» —
  смена темы Windows сразу перекрашивает Snapkit. Затемнение экрана при выделении — тёмное.
- [ ] **10. Цвет программы (2.7).** Каждый из 12 кружков: образец меняется сразу; после
  «Сохранить» — кнопки, рамка выделения, кружки заметок на ленте и на вставленной картинке.
- [ ] **11. Перенос (2.8).** После установки поверх 0.3.1 клавиши пользователя (Print Screen
  и Ctrl+F12) — в полях окна и работают.
- [ ] **12. Обновление (2.9).** На следующем настоящем релизе: уведомление «Вышла версия… —
  обновить?», «Обновить» — новая версия встаёт на место, «Snapkit обновлён до версии…»,
  лента на месте. Закрытое без «Обновить» уведомление не повторяется до следующих суток.
- [ ] **13. Удаление (2.10).** Строка «Snapkit» есть в «Параметры → Приложения». Удаление из неё
  (и из настроек): вопрос, затем нет программы, ярлыка, автозапуска, строки в «Приложениях»,
  `%LOCALAPPDATA%\Snapkit` и `%APPDATA%\Snapkit`; сохранённые снимки на месте.
  Проверять в конце, после всего остального — Snapkit потом поставить заново.
